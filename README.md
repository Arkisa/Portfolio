# Cris Joseph Arquiza — Portfolio

A personal portfolio site built with an ink-brush, samurai-inspired visual theme — showcasing selected web and desktop projects, with a light/dark mode toggle and animated ambient effects.

## ◆ Technologies Used

- **HTML5** / **CSS3** (custom properties / design tokens for theming)
- **Vanilla JavaScript** (no frameworks — handles nav, theme toggle, boot animation, particle effects)
- **Google Fonts** — Yuji Syuku, Shippori Mincho, Noto Sans JP

**Featured projects showcased on the site:**
| Project | Stack |
|---|---|
| Craveh | HTML, CSS, JavaScript, PHP, MySQL |
| Weather App | Vue, C#, XAML, MVVM, SQLite, Open-Meteo API |
| Studymate | HTML, CSS, JavaScript, PHP, MySQL |

## ◆ Setup Instructions

This is a static site — no build step or dependencies required.

**Run locally:**
1. Clone the repo:
   ```bash
   git clone https://github.com/Arkisa/Portfolio.git
   cd Portfolio
   ```
2. Open `index.html` directly in your browser, or serve it locally (recommended, avoids any path issues):
   ```bash
   npx serve .
   ```
